# Generated Projections

Generated projections are derived outputs. They are not protocol source of
truth.

Any generated projection retained in this repository must record:

- source registry version or digest;
- source schema version or digest;
- source mapping version or digest;
- generator name;
- generator version;
- generation command;
- generated surface version/stamp;
- source commit or release tag where available;
- conformance profile used for validation.

OpenAPI, SDK operation constants, and SDK envelope/status/error types are
projection surfaces, not protocol authority.
