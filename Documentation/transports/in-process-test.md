# In-Process Test Transport

In-process test transport is a non-product transport for conformance harnesses and deterministic API tests.

## Artifact References

- ``transports/in-process-test.v1.md``
- ``transports/in-process-test/``

## Contract Model

The in-process transport covers harness boundary, purpose, error behavior, non-product limitations, security limitations, and conformance profile.

## Operation Relationship

Allowed operations are controlled by `mappings/operation-transport-map.v1.json` and related mapping policy. Transport docs describe how operations are carried; operation docs define what operations mean.
