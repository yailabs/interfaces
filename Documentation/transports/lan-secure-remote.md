# LAN Secure Remote

LAN secure remote defines controlled local-network exposure for explicitly allowed operations.

## Artifact References

- ``transports/lan-secure.v1.md``
- ``transports/lan-secure/``

## Contract Model

LAN exposure requires pairing, device allowlists, endpoint binding, operation exposure policy, revocation, and security posture.

## Operation Relationship

Allowed operations are controlled by `mappings/operation-transport-map.v1.json` and related mapping policy. Transport docs describe how operations are carried; operation docs define what operations mean.
