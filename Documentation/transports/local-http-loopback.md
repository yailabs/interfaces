# Local HTTP Loopback

Local HTTP loopback exposes local API operations over loopback HTTP routes.

## Artifact References

- ``transports/local-http-loopback.v1.md``
- ``transports/local-http-loopback/``

## Contract Model

Loopback HTTP binds operations to routes, headers, local client tokens, origin/CORS policy, request/response shape, errors, and platform bindings.

## Operation Relationship

Allowed operations are controlled by `mappings/operation-transport-map.v1.json` and related mapping policy. Transport docs describe how operations are carried; operation docs define what operations mean.
