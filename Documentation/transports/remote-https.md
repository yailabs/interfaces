# Remote HTTPS

Remote HTTPS documents future or managed remote API boundaries without making remote hosting the default runtime truth.

## Artifact References

- ``transports/remote-https.v1.md``
- ``transports/remote-https/``

## Contract Model

Remote HTTPS covers account auth, machine/license boundaries, platform boundary, release/update boundary, security, and error behavior.

## Operation Relationship

Allowed operations are controlled by `mappings/operation-transport-map.v1.json` and related mapping policy. Transport docs describe how operations are carried; operation docs define what operations mean.
