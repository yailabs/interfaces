# Case Domain

The case domain documents API-facing case references, roots, tree projection, URI grammar, and case operation behavior.

## Absorbed Semantics

- Work root case and root case projection.
- Case URI grammar and normalization.
- Case tree model and manifest projection.
- Case operations such as root, list, open, close, enter, leave, and status.
- Case evidence and job binding boundaries that appear through the API.
