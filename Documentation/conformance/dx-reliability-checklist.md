# DX Reliability Checklist

Developer experience reliability is part of SDK conformance.

## Checklist

- Package READMEs point to canonical SDK docs.
- Quickstart and examples avoid fake readiness claims.
- Package validation commands are documented.
- Error/status handling preserves API semantics.
- Compatibility aliases have canonical replacements or explicit limits.
- Generated and extracted surfaces are indexed.
- Cross-repo boundaries are clear: API protocol, YAI runtime, Console terminal UX.
