# SDK Examples

SDK examples demonstrate official package consumption:

- Rust: `packages/rust`, `yai-sdk-rust`
- Python: `packages/python`, `yailabs-yai-sdk`, import `yai_sdk`
- TypeScript: `packages/typescript`, `@yailabs/sdk`
- C: `packages/c`, include prefix `<yai_sdk/...>`

SDK examples must stay aligned to protocol docs and package compatibility. They
must not introduce new operation, transport, envelope, or error truth.
