# Examples

Examples documents protocol and SDK example boundaries for YAI Interfaces.

## Current Phase

Protocol/API examples may live in this repository now. SDK package examples
remain with `../sdk` until SDK drain, then move under `interfaces/examples/`
or package-local example directories after classification.

## Example Categories

- Protocol examples.
- Rust SDK examples after drain.
- Python SDK examples after drain.
- TypeScript SDK examples after drain.
- C SDK examples after drain.
- External client authoring examples.
- Local runtime connection examples.

## Rules

- Examples consume interface contracts.
- Examples do not define protocol truth.
- Examples must not imply runtime features are implemented when conformance or
  readiness marks them unavailable, blocked, deferred, or not implemented.
