# Family Availability

Family availability describes which API-aligned SDK surfaces are available, deferred, compatibility-only, or unavailable by package.

## Rules

- Availability derives from API registry and package implementation evidence.
- Deferred families must not be represented as complete.
- Compatibility-only families must be labeled as compatibility-only.
- Release notes must tie availability claims to package validation evidence.

Use `conformance/api-inventory.md` for inventory alignment.
