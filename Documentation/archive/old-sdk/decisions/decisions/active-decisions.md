# Active Decisions

## SDK Package Authority

The SDK repository owns typed client consumption, language package behavior, SDK compatibility, generated surface boundaries, SDK release/versioning, conformance, and developer experience.

## Cross-Repo Boundary

API owns protocol and transport truth. YAI owns runtime and system truth. Console owns terminal command and TUI UX truth.

## Compatibility

Compatibility aliases and C/native transitional surfaces may remain only when clearly labeled and validated. They do not define canonical protocol grammar.
