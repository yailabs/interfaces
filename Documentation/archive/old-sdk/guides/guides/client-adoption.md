# Client Adoption

Client adoption means consuming SDK package APIs instead of direct runtime adapters.

## Adoption Rules

- Use SDK packages for typed client behavior.
- Use API documentation for protocol and transport truth.
- Use YAI documentation for runtime/system truth.
- Use Console documentation for terminal UX truth.
- Treat compatibility aliases as migration aids, not canonical surface expansion.

## Migration Gate

A client is ready for SDK adoption when package validation, API inventory alignment, transport configuration, and error/status handling are explicit.
