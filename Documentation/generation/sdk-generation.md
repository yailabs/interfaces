# SDK Generation

SDK generated material is a package projection over YAI Interfaces protocol
truth.

SDK operation constants, envelope types, typed clients, and language-native
helpers may be generated or hand-maintained, but they must remain traceable to:

- operation registry inputs;
- schema inputs;
- mapping inputs;
- generator identity and version;
- source commit or release;
- conformance profile.

SDK operation constants and envelope types are package projections pending
INTF.6 validation hardening.
