# Remote HTTPS Future Hosted Capability Boundary v1

## Purpose

Reserve `remote_https` for future hosted capability only when explicitly
contracted later.

## Rules

- hosted or remote capability must be explicit and opt-in
- future hosted capability does not imply hosted compute is implemented now
- Remote HTTPS must not be treated as a generic remote inference API by
  default

## Boundary

- API.07 does not implement hosted compute
